# Swedbank Fund Charts

A lightweight public website that displays each Swedbank fund's six-month NAV history on a single page.

## Stack

- React + TypeScript + Vite
- Recharts for charts
- JSON files for published data
- Node.js + TypeScript for data collection
- GitHub Actions for daily updates
- Cloudflare Pages for static hosting

## Status

Initial project scaffold is being prepared. The data-source adapter must be verified against Swedbank's current public endpoints before real prices are published. No sample values are presented as real financial data.

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
